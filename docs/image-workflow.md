# 제품·상품 이미지 제작 규칙

제품 또는 상품 이미지가 새로 첨부되면 원본을 그대로 배치하지 않고 ONSHIVE
사이트의 에디토리얼 톤에 맞춰 웹용 비주얼을 제작하거나 보정한 뒤 적용합니다.

## 시각 기준

- 기본 팔레트: warm ivory `#f3efe4`, charcoal `#1b1c19`, honey gold
  `#b0821a`
- 산업적이고 정돈된 제품 카탈로그와 편집 디자인의 중간 톤
- PET과 PRINT 이미지는 같은 크롭 규칙, 조도와 정보 밀도를 사용
- 제품 라벨, 로고, 패키지 문구와 실제 색상은 임의로 바꾸지 않음
- 제품에 없는 기능·인증·성능·구성품을 생성하지 않음
- 배경과 보조 소품은 제품보다 눈에 띄지 않게 구성
- 이미지 안에 AI가 생성한 글자를 넣지 않음

## 처리 순서

1. 원본을 비공개 작업 폴더에 보존하고 파일 해시와 제공일을 기록합니다.
2. 실제 제품 외형을 바꾸지 않는 범위에서 배경, 조명, 여백과 구도를 생성·보정합니다.
3. 정사각형 제품 카드와 필요 시 16:9 현장 배너를 제작합니다.
4. 공개 파일은 WebP로 최적화해 `public/images/commerce/`에 저장합니다.
5. 너비·높이, 의미 있는 대체 텍스트와 적용 페이지를 기록합니다.
6. 데스크톱·모바일 크롭과 제품 라벨 가독성을 확인합니다.

## 기록 항목

각 이미지 업데이트는 다음을 `docs/image-assets.md`에 남깁니다.

- 원본 파일명 또는 사용자 첨부 식별자
- 생성·보정 목적과 사용한 지시문 요약
- 공개 파일 경로와 실제 표시 위치
- 원본과 결과물의 SHA-256
- 사실 표현을 바꾸지 않았다는 검수 결과

이미지가 없는 영역은 실제 상품처럼 보이는 임의 제품을 만들지 않고 자료 준비
상태를 유지합니다.
